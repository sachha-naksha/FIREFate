Cross-prediction
~~~~~~~~~~~~~~~~
Stratifying uncommitted populations for fate bias using cellular programs inferred
from an intervention against unperturbed controls (capability 7).

This module is scaffolded but not yet ported: the work currently lives outside the
Python package, in ``SLIDE/Crossprediction.R`` and ``TF_Dynamic_Activity/``. It
exports nothing yet.
